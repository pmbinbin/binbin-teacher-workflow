# 彬彬-教师公开课工作流（binbin-teacher-workflow）

> Marvis 技能（Skill）· 教师公开课备课端到端工作流
> 版本：v1.0.0 ｜ 适用平台：macOS / Windows（Marvis 客户端均可加载）

## 简介

为教师公开课备课提供端到端工作流：只需给出大致主题方向（如"八年级语文《背影》公开课"），即可对话式补齐必要信息、自动搜集资料，并产出教学设计、PPT、互动网页、课堂工具等全套初稿，全程保留教师决策点，第一版不视为最终成品。

## 功能特性

- **轻量输入**：只需提供课程主题方向，其余参数由对话式采集补齐
- **资料搜集与整理**：优先课程标准、正规教育机构与公开教研来源；不绕过付费、登录或版权限制，无法合法保存全文时只建资料卡
- **四类初稿产出**：教学设计（.docx）、PPT（.pptx，16:9）、互动网页（单文件 HTML）、课堂工具箱（单文件 HTML）
- **课堂工具箱三模块**：随机点名器、课堂倒计时、班级音量提示器（仅本地读取音量，不录音不上传）
- **人工确认点保留**：教学目标/互动创意由教师决定、文件操作前确认、初稿不标记最终、试讲通过才算完成

## 安装方法

1. 解压本压缩包，得到 `binbin-teacher-workflow/` 目录
2. 将整个目录放入 Marvis 用户目录下的技能库：
   - `.../MarvisData/User/<用户ID>/skills/custom/binbin-teacher-workflow/`
3. 重启或刷新 Marvis 客户端，在"我的技能"中确认显示名「彬彬-教师公开课工作流」

## 使用方法

直接口语化触发即可，例如：

> "用彬彬-教师公开课工作流，帮我准备一节八年级语文《背影》公开课。"

技能会自动进入参数采集：依次询问是否有现成资料文件夹、教学目标/互动创意是否已定、输出到哪；回答"没有"或"你帮我找"的部分，由 AI 自行搜集或生成建议，并在开始整理前向教师复述确认。

### 教师需准备

1. 只需给出课程主题方向
2. 对"是否有现成资料 / 目标是否已定 / 创意是否已定"三个问题如实回答（有则给路径或内容，没有则授权 AI 代找）
3. 预留至少 4 个确认时点：参数采集复述、资料补充、课堂结构、初稿审核

## 执行流程概览

| 步骤 | 动作 | 产出 | 确认点 |
|---|---|---|---|
| 0 | 参数采集：接收主题方向，逐项询问资料/目标/创意/输出位置 | 参数清单 | 采集完成后复述 |
| 1 | 读取资料并输出资料清单；缺资料则由 AI 按版权约束搜集落盘 | 资料清单 | — |
| 2 | 对照教学目标提出缺失关键信息，教师补充 | 缺失信息清单 | 教师补充后才继续 |
| 3 | 文件分类方案，确认后物理整理 | 分类方案 | 确认后才整理 |
| 4 | 课堂结构草案（时间/活动/资料/互动） | 结构草案 | 教师确认后才细化 |
| 5 | 四类初稿：教学设计、PPT、互动网页、课堂工具箱 | 初稿文件 | 初稿标注"初稿" |
| 6 | 收集教师反馈，逐项修改 | 修订版 | 覆盖/移动需确认 |
| 7 | 输出修改记录与最终清单 | 修改记录 + 清单 | 教师审核并试讲后才算完成 |

## 人工确认点（必须保留）

1. 教学目标和互动创意由教师决定：已给定的不得替换；未定的 AI 仅提供建议，最终由教师拍板
2. 文件移动、覆盖、重命名、删除前必须向教师确认
3. 第一版不能标记为最终成品，所有初稿标注"初稿"
4. 教师审核并试讲通过后任务才算完成
